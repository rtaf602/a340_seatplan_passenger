เว็บกรอกผังที่นั่งผู้โดยสาร A340 · 1 Sector = 1 ภารกิจ = 1 แท็บ ในไฟล์ Google Sheet **Seat Plan A340 TEMPORARY FOR PASSENGER**
อ่านสภาพที่นั่ง/จอ Monitor (พร้อม NOTE) จากไฟล์ **Seat Plan 340 (For Admin)**

หน้าเว็บ: https://rtaf602.github.io/a340_seatplan_passenger/

## การใช้งาน

1. **เข้าเว็บ**: กด Sign in with Google (เมื่อตั้ง Client ID แล้ว) และใส่รหัสเข้าใช้งาน
   - ใช้ได้ **90 นาที** (บัตรผ่านเว็บไซต์ ภารกิจ ADMIN และการดูภารกิจที่เสร็จสิ้น ใช้นาฬิกาเดียวกัน) ก่อนหมด 5 นาทีมีข้อความ กด **ต้องการใช้งานต่อ** ได้อีกครั้งละ 90 นาที (ไม่จำกัดครั้ง) · กด **ปิดข้อความ** จะออกจากระบบเมื่อครบเวลา
   - **รีเฟรชหน้าเว็บ** ใช้งานต่อได้ไม่ต้องใส่รหัสใหม่ · **ปิดแท็บ / ปิดเบราว์เซอร์ / เปิดแท็บใหม่** ต้องเข้าสู่ระบบใหม่
   - ปุ่ม **ออกจากระบบ** มุมบนขวาทุกหน้า ถ้ามีรายการยังไม่ SAVE จะถามก่อน: SAVE ก่อน / ทิ้งรายการที่ยังไม่ SAVE / ยกเลิก
   - ออกจากระบบด้วยเหตุใดก็ตาม (หมดเวลา ถูกบล็อก มีคนเข้าซ้อน) สิ่งที่กรอกแต่ยังไม่ SAVE ยังอยู่ในเครื่องนั้น
2. **รายการภารกิจ**: แท็บ ภารกิจที่เปิดอยู่ / ภารกิจที่เสร็จสิ้นเรียบร้อย / ภารกิจทั้งหมด และเลือกห้วงวันที่บินได้
   - **+ เปิดภารกิจใหม่**: Sector, เที่ยวบิน, ชื่อภารกิจ, เส้นทางบิน (IATA), วันที่บิน, รหัสภารกิจ, ชื่อผู้บันทึก
   - เข้าภารกิจต้องใส่ **รหัสภารกิจ** ทุกครั้ง
   - แท็บ **ภารกิจที่เสร็จสิ้นเรียบร้อย** และ **ภารกิจทั้งหมด** ต้อง Login ด้วย Username, Password, เลขบัตรข้าราชการ และวันเดือนปีเกิด (ใช้ได้ 2 ชั่วโมง) ผู้ใช้ทั่วไปเห็นเฉพาะภารกิจที่เปิดอยู่
   - **เปลี่ยนรหัสภารกิจ / ปิดภารกิจ / เปิดภารกิจอีกครั้ง** ต้องยืนยันด้วย Username, Password, เลขบัตรข้าราชการ และวันเดือนปีเกิด (ตรวจกับ LOGIN DATABASE) การเปิดอีกครั้งต้องใช้รหัสภารกิจด้วย
3. **ผังที่นั่ง**: แตะที่นั่งเพื่อกรอก ยศ/ชื่อ/สกุล ภาษาไทย และภาษาอังกฤษ ที่นั่งแสดงชื่อย่อ (มานะ พ. / Mana P.)
   - ปุ่ม **CLEAR** (ล้างเฉพาะรายชื่อ) · **SAVE** (ต้องกรอกชื่อผู้บันทึกทุกครั้ง) · **PREVIEW** · **EXPORT TO PDF** · **PRINT BOARDING PASS**
   - **ที่นั่งคงเหลือ** รวมทั้งลำ (หัก CREW ZONE และที่นั่งที่มีชื่อแล้ว) แสดงใต้ปุ่ม และแยกรายโซน · ที่นั่งใช้ไม่ได้ยังใส่ชื่อได้ (กรณีที่นั่งไม่พอ) จึงนับเป็นที่นั่งคงเหลือ และบอกจำนวนไว้ในวงเล็บ
   - **บันทึกพร้อมกันหลายเครื่อง**: หน้าเว็บตรวจทุก 10 วินาที ถ้ามีคนอื่น SAVE ระหว่างที่เรายังมีรายการค้าง ขึ้นแถบเหลือง 🔔 พร้อมปุ่ม **โหลดล่าสุด** (ไม่มีรายการค้าง ผังอัปเดตเอง)
     กด SAVE แล้วมีคนแทรก ระบบโหลดล่าสุดและ SAVE ต่อให้เอง · ถ้าแก้ที่นั่ง / ช่องเดียวกับที่คนอื่นเพิ่งบันทึก ขึ้นหน้าต่างให้เลือกทีละรายการว่า **ใช้ของคุณ** หรือ **ใช้ในระบบ** (ต้องเลือกครบ ระบบไม่เลือกให้) · ยกเลิก = ยังไม่บันทึกอะไร
   - **รหัสภารกิจถูกเปลี่ยน** ระหว่างใช้งาน: ขึ้นหน้าต่างให้กรอกรหัสใหม่ สิ่งที่กรอกไว้ยังอยู่
   - **EXPORT TO EXCEL** (หน้าผู้โดยสาร, หน้า ADMIN และในหน้า PREVIEW): ไฟล์ .xlsx แก้ไขได้ หน้าตาและการแบ่งหน้า A4 เหมือน PDF เลือกได้ว่า "มีรายชื่อที่ SAVE แล้ว" หรือ "ฟอร์มเปล่า" ไว้กรอกเอง
   - ชื่อไฟล์ PDF: `261013_10.44 TH-LT_RTAF201_Seat Plan A340 (Pax).pdf` (เวลาไทย)
4. **ADMIN** (ปุ่มด้านล่าง ต้อง Login): แสดงที่นั่งลูกเรือคงเหลือ (เฉพาะ CREW ZONE) · ที่นั่งใช้ไม่ได้ใส่ชื่อลูกเรือได้ · กั้น CREW ZONE จากหัว/ท้ายเครื่อง (หัวเครื่องเลือกได้ว่าไม่กั้น, ห้อง Mission Commander เท่านั้น, เริ่มจากห้อง Mission Commander ถึงแถวที่เลือก หรือเริ่มจากแถว 1 ถึงแถวที่เลือก) กรอกรายชื่อลูกเรือ และ PREVIEW / PDF `(CREW)` / Boarding Pass ลูกเรือ · LOGOUT เมื่อเสร็จ
5. **Boarding Pass** 203 × 82.5 มม. A4 ได้ 3 ใบ/แผ่น จัดกึ่งกลาง (ขอบบน-ล่าง 22.75 มม., ข้าง 3.5 มม., ห่างกัน 2 มม., รอยตัดอยู่ในขอบกระดาษ)
   ในหน้าต่างพิมพ์ให้ตั้ง **Scale 100%**, **Margins: None** และเปิด **Background graphics**

## เข้าใช้งานซ้อน

| รหัส / บัญชี | ใช้พร้อมกัน |
|---|---|
| รหัสผ่านเว็บไซต์ · รหัสภารกิจ | หลายเครื่องได้ ไม่จำกัด |
| บัญชี Google (Email) | ทีละ 1 หน้าต่าง |
| Username (หน้า ADMIN · ดูภารกิจที่เสร็จสิ้น / ทั้งหมด) | ทีละ 1 หน้าต่าง (เปิดภารกิจใหม่ · เปลี่ยนรหัส · ปิด/เปิดภารกิจ เป็นการยืนยันครั้งเดียว ไม่นับ) |

ถ้า Email / Username ที่ใช้อยู่ที่เครื่อง A ถูกใช้ Login ที่เครื่อง B (กรอกถูกครบทุกช่องแล้ว):
- เครื่อง B เห็น "กำลังรอเครื่องเดิมออกจากระบบ" · เครื่อง A เห็นข้อความภายในประมาณ 10 วินาที พร้อมนับถอยหลัง 10 วินาที และปุ่ม **ไม่อนุญาต ฉันกำลังใช้งานอยู่**
- A กดไม่อนุญาต → A ใช้ต่อ B ได้ข้อความว่าเครื่องเดิมไม่อนุญาต · A ไม่กด → A ถูกออกจากระบบ B ได้เข้า · A ปิดไปแล้ว / ไม่ได้ถามระบบเกิน 30 วินาที → B เข้าได้เลย
- เครื่องที่สามขอเข้าขณะ B รออยู่ → ให้รอสักครู่แล้วลองใหม่ · B ปิดหน้ารอ → คำขอยกเลิกเอง
- Password ใน LOGIN DATABASE ถูกเปลี่ยน → หน้า ADMIN / การดูภารกิจที่เสร็จสิ้นที่ Login ด้วย Password เดิมถูกออก
- ทุกเหตุการณ์บันทึกในแท็บ `HISTORY LOGIN DATA` (TAKEOVER_REQUEST / TAKEOVER_DENIED / TAKEOVER)
- หมายเหตุ: เบราว์เซอร์ชะลอแท็บที่ไม่ได้เปิดดูอยู่ ถ้า A สลับไปแท็บ/แอปอื่นนานเกิน 30 วินาที B อาจเข้าได้โดย A ไม่เห็นข้อความ

## การล็อกเมื่อใส่รหัสผิด

กติกาเดียวกันทุกรหัส: **ผิดติดกัน 5 ครั้ง พัก 60 นาที · ผิดอีก 5 ครั้ง บล็อก** จนแอดมินแก้ช่องสถานะเป็น `ACTIVE` ในไฟล์ Admin Page

| ใส่ผิดตอน | นับที่ | ปลดบล็อก |
|---|---|---|
| รหัสผ่านเว็บไซต์ | Email | แท็บ `LOCKED EMAILS` |
| รหัสภารกิจ (เข้าภารกิจ) | Email | แท็บ `LOCKED EMAILS` |
| Login ด้วย LOGIN DATABASE (เปิดภารกิจใหม่, เปลี่ยนรหัสภารกิจ, ปิด/เปิดภารกิจ, ADMIN) รวมรหัสภารกิจตอนปิด/เปิดภารกิจ | Username และ Email | แท็บ `LOCKED USERS` และ `LOCKED EMAILS` |

Email ที่ถูกพักหรือบล็อกเข้าเว็บไซต์ไม่ได้ Username ที่ถูกพักหรือบล็อก Login ไม่ได้จากทุกอีเมล
แอดมินแก้สถานะเป็น `BLOCKED` เอง: เครื่องที่ใช้ Email / Username นั้นอยู่ถูกออกจากระบบภายในประมาณ 20 วินาที (สถานะ PAUSED ไม่ตัดออก)

## ติดตั้ง / อัปเดตระบบหลังบ้าน

> Repo นี้เป็น public **ห้ามใส่รหัสผ่าน หรือรหัสไฟล์ Google Sheet ลงในไฟล์ใดของ repo** ค่าเหล่านี้กรอกในหน้า Apps Script เท่านั้น

1. เปิดไฟล์ **Seat Plan A340 TEMPORARY FOR PASSENGER** → **ส่วนขยาย › Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) แล้วกรอกส่วน `SETUP` ด้านบน (รหัสเข้าใช้งาน, ลิงก์ไฟล์ทั้ง 4, Google Client ID ถ้ามี)
3. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์ ดูผลในบันทึกการดำเนินการ (ระบบสร้างแท็บประวัติให้เอง) เสร็จแล้วลบค่าใน `SETUP` ออกได้
   (ระบบจำค่าตั้งระบบไว้ 10 นาที ถ้าแก้ Script Properties ด้วยมือ ให้รัน `setup` อีกครั้งเพื่อให้มีผลทันที)
4. **ทำให้ใช้งานได้ › จัดการการทำให้ใช้งานได้ › แก้ไข (ดินสอ) › เวอร์ชัน: เวอร์ชันใหม่ › ทำให้ใช้งานได้** (URL เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`)
   ติดตั้งครั้งแรก: **การทำให้ใช้งานได้รายการใหม่** → เว็บแอป · ดำเนินการในฐานะ **ฉัน** · ผู้มีสิทธิ์เข้าถึง **ทุกคน** แล้วใส่ URL `/exec` ใน `config.js`

### Sign in with Google (เก็บอีเมลผู้ใช้)

1. https://console.cloud.google.com/ → สร้างหรือเลือกโปรเจกต์ → **APIs & Services › OAuth consent screen** ตั้งค่าแบบ External
2. **Credentials › Create credentials › OAuth client ID** → ประเภท **Web application**
3. **Authorized JavaScript origins** ใส่ `https://rtaf602.github.io`
4. คัดลอก Client ID (ลงท้าย `.apps.googleusercontent.com`) ใส่ `SETUP.googleClientId` แล้วรัน `setup` อีกครั้ง

ยังไม่ใส่ Client ID ก็ใช้งานได้ แต่ประวัติจะไม่มีอีเมล
