# SEAT PLAN A340 · ผังที่นั่งผู้โดยสารชั่วคราว

เว็บผังที่นั่งผู้โดยสาร A340 แยก 1 ภารกิจ ต่อ 1 แท็บ ในไฟล์ Google Sheet
**Seat Plan A340 TEMPORARY FOR PASSENGER** และอ่านสภาพที่นั่ง/จอ Monitor สดจากไฟล์ **Seat Plan 340 (For Admin)**

- หน้าเว็บ: https://rtaf602.github.io/a340_seatplan_passenger/
- ทดลองโดยไม่เชื่อม Google Sheet: https://rtaf602.github.io/a340_seatplan_passenger/?demo=1 (ข้อมูลเก็บในเบราว์เซอร์นั้นเท่านั้น)

## การใช้งาน

1. เข้าเว็บครั้งแรกต้องใส่รหัสผ่าน (จำไว้จนปิดแท็บ)
2. หน้า **รายการภารกิจ** → กด **+ เปิดภารกิจใหม่** ระบบสร้างแท็บใหม่ใน Google Sheet ให้ หรือแตะภารกิจเดิมเพื่อเปิดผังที่นั่ง
3. หน้า **ผังที่นั่ง**
   - ข้อมูลภารกิจ: ประเภทเครื่องบิน (A340 ล็อกไว้) · ชื่อภารกิจ · เที่ยวบินที่ · Sector · วัน-เดือน-ปี (เลือกแยกช่อง) · GATE · BOARDING TIME · หมายเหตุ Boarding Pass
   - แตะที่นั่งเพื่อกรอก ยศย่อ (ไทย) · ชื่อ-สกุล (ไทย) · ยศย่อ (อังกฤษ) · ชื่อ-สกุล (อังกฤษ ตัวพิมพ์ใหญ่) — เลือกยศไทยแล้วระบบเติมยศอังกฤษให้
   - ปุ่ม **CLEAR** (ลบทั้งหมด) · **SAVE** · **PREVIEW** · **EXPORT TO PDF** · **PRINT BOARDING PASS** — PREVIEW / PDF / Boarding Pass ใช้ข้อมูล SAVE ล่าสุด ถ้ามีรายการยังไม่ SAVE จะเตือนก่อน
   - ชื่อไฟล์ PDF: `ปีเดือนวัน_ชม.นาที TH-LT_เที่ยวบิน_Seat Plan A340.pdf` เช่น `261013_10.44 TH-LT_RTAF201_Seat Plan A340.pdf` (เวลาไทย)
   - ป้ายแต่ละโซนแสดง **จำนวนที่นั่งว่าง** (ไม่นับที่นั่งที่มีผู้โดยสาร ที่นั่งใช้ไม่ได้ และ CREW ZONE)
   - ปุ่ม **ADMIN** ด้านล่าง: กั้นที่นั่งให้ลูกเรือจากหัวเครื่องถึงแถวที่เลือก / จากท้ายเครื่องถึงแถวที่เลือก (ขึ้น **CREW ZONE** สีแดง ผู้โดยสารกรอกไม่ได้) และ PRINT BOARDING PASS
4. **Boarding Pass** ขนาดจริง 203 × 82.5 มม. พิมพ์ A4 ได้ 3 ใบ/แผ่น (ขอบข้าง 3.5 มม., ขีดตัด 6 แนว, แถบล่าง 42 มม. ตัดทิ้ง) หรือกระดาษขนาดบัตร
   ในหน้าต่างพิมพ์ให้ตั้ง **Scale 100%**, **Margins: None** และเปิด **Background graphics**

ทุกการ SAVE บันทึกประวัติไว้ในแท็บของภารกิจนั้น (คอลัมน์ J เป็นต้นไป) และดูได้ที่หัวข้อ “ประวัติการบันทึกของภารกิจนี้” ในหน้าเว็บ

## โครงสร้างแท็บภารกิจใน Google Sheet

| ส่วน | ตำแหน่ง |
|---|---|
| ข้อมูลภารกิจ | A3:B10 |
| CREW ZONE หัวเครื่อง / ท้ายเครื่อง (ถึงแถว) | B12 / B13 |
| รายชื่อผู้โดยสาร 165 ที่นั่ง | A16:H (ที่นั่ง, โซน, ยศไทย, ชื่อไทย, RANK, NAME, ผู้บันทึก, เวลา) |
| ประวัติการบันทึก | J2:O |

แท็บ **รายการภารกิจ** เป็นสารบัญ (ID = gid ของแท็บ) ชื่อแท็บเปลี่ยนเป็น “เที่ยวบิน วันที่” อัตโนมัติเมื่อ SAVE

## ติดตั้ง (ครั้งเดียว)

> Repo นี้เป็น public **ห้ามใส่รหัสผ่านลงใน `config.js` หรือไฟล์ใดใน repo** ให้ตั้งรหัสใน Apps Script เท่านั้น

1. เปิดไฟล์ Google Sheet **Seat Plan A340 TEMPORARY FOR PASSENGER** → เมนู **ส่วนขยาย › Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. แก้บรรทัด `const ACCESS_PIN = '';` ใส่รหัสผ่านเข้าใช้งานระหว่างเครื่องหมาย `'...'`
4. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (ต้องเป็นบัญชีที่เปิดไฟล์ Seat Plan 340 (For Admin) ได้) ในบันทึกต้องขึ้น “อ่านสภาพที่นั่งจากไฟล์ Admin ได้ … รายการ”
5. **ทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป** · ดำเนินการในฐานะ **ฉัน** · ผู้มีสิทธิ์เข้าถึง **ทุกคน** → คัดลอก URL ที่ลงท้าย `/exec`
6. ใส่ URL นั้นใน `API_URL` ของไฟล์ [`config.js`](config.js) แล้ว commit

แก้โค้ด Apps Script ภายหลัง: **ทำให้ใช้งานได้ › จัดการการทำให้ใช้งานได้ › แก้ไข › เวอร์ชันใหม่** (URL เดิมใช้ต่อได้)
